## 2. Термінологічні рішення

| International | Обраний український варіант | Обґрунтування |
|---|---|---|
| Irradiance / irradiation | опроміненість G [W/m²] / сумарне опромінення H [kWh/m²] | Термінологія ДСТУ для енергетичної освітленості; «інсоляцію» не використовуємо як одиницю |
| Solar cell | сонячний елемент (комірка) | «Елемент» — нормативно; «комірка» — уживано (CURRICULUM); подаємо обидва при першій появі, далі «комірка» |
| Bypass diode | обхідний (шунтувальний) діод | Уникаємо кальки «байпасний»; «bypass-діод» лишаємо як міжнародний термін |
| String | ланцюжок модулів (стрінг) | «Стрінг» — професійний жаргон, подаємо в дужках |
| PWM / SPWM | ШІМ / синусоїдна ШІМ | Усталена українська абревіатура «широтно-імпульсна модуляція» |
| Carrier | несуча | Термін теорії модуляції |
| DC link | DC-ланка (ланка постійного струму) | Коротко й зрозуміло |
| Shoot-through / dead time | наскрізний струм / мертвий час | Усталені в силовій електроніці |
| Islanding | острівний режим (острів) | Усталене в енергетиці |
| Self-sufficiency / self-consumption | самодостатність / самоспоживання (частка самоспоживання) | Розрізняємо два показники, які часто плутають |
| Backup reserve | резерв SOC (резерв заряду) | Як у меню гібридних інверторів українською |
| UPS | UPS — ДБЖ (джерело безперебійного живлення) | Міжнародне першим, ДБЖ — локальний відповідник |
| Thermal runaway | тепловий розгін | Описовий, без кальки «термальний» |
| Lithium plating | осадження (металевого) літію | Без кальки «літієве плакування» |
| SEI | твердоелектролітна міжфазна плівка (SEI) | Повний науковий відповідник; у тексті далі «плівка SEI» |
| DSO | ОСР — оператор системи розподілу | Термін Закону «Про ринок електричної енергії» |
| SPD | пристрій захисту від імпульсних перенапруг (у побуті — УЗІП/ОПН) | Узгодити з розділом `home` (C5), де теж є SPD |
| Prosumer | активний споживач (просьюмер) | «Активний споживач» — термін українського законодавства |

Узгодити з C5 (`home`, `distribution`) і C1 (`matter`): однакові відповідники для SPD, RCD (ПЗВ), DSO (ОСР), p-n переходу.

## 3. Наскрізні об'єкти лабораторій (для будівників)

Чотири лабораторії свідомо мають **спільні вигадані «лабораторні» компоненти** з узгодженими параметрами — їх варто
реалізувати як спільні ассети/моделі:
- **ЛМ-440** — модуль 440 Wp (108 половинок, V_oc 39,4 V, I_sc 13,9 A) — `lab-pv` §M1; використовується в `lab-inverter` (кр. 7) і `lab-hybrid-home` (дах 12 шт.).
- **ЛІ-6** — однофазний гібридний інвертор 6 kW / 48 V (MPPT 125–425 V, макс. 500 V, 2 MPPT, пік 12 kW 10 s, холостий хід 50 W,
  модель ККД `lab-inverter` §M5) — у всіх чотирьох лабораторіях.
- **Батарея 51,2 V** — 16S1P/16S2P LFP-100 (5,12 / 10,24 kWh), `lab-battery` §M4; у `lab-hybrid-home` — 10,24 kWh.
- **Дім-лабораторія** (`labHouse`) — той самий будинок у `lab-pv` (кр. 8–9) і `lab-hybrid-home`; бажано — той самий, що в
  розділі `home` (CURRICULUM: «лабораторії живуть у будинку наприкінці шляху») — **рішення за оркестратором**.

## 4. Залежності від сусідніх розділів

- `matter` (C1): p-n перехід, E_g(Si) = 1,12 eV, напрям вбудованого поля (від n до p) — `lab-pv` кр. 2 посилається.
- `generator-ac` (C2): синхронізація, P/Q, фазори — `lab-inverter` кр. 8 посилається; `transformer` — ВЧ-трансформатор (кр. 6).
- `transmission` (C2): HVDC VSC/MMC — `lab-inverter` кр. 11.
- `distribution` (C2): системи заземлення TN-C-S, ОСР, розподілена генерація — `lab-hybrid-home` кр. 10, 12.
- `plant-solar` (C4): СЕС, трекери, duck curve — `lab-pv` кр. 8 і фінал посилаються; `plant-future` (C4): BESS — `lab-battery` кр. 12.
- `grid` (C5): відключення, відновлення, VPP — `lab-hybrid-home` кр. 12. `home` (C5): SMPS-випрямляч (`lab-inverter` кр. 1),
  щиток/RCD/SPD, кр. 11 «Резервне живлення» має **лише анонсувати** UPS/гібриди — детально вони в лабораторіях.

## 5. Моделі й контрольні точки

Усі контрольні значення отримано довідковими скриптами (Python 3, лише стандартна бібліотека) на lenovo:
`/srv/electricity/qa/C6-labs/` — `pv_model.py`, `mppt_po.py`, `orient_model.py` (+ `pvgis_kyiv_grid.txt`), `inverter_model.py`,
`inv_extra.py`, `battery_model.py`, `thermal_model.py`, `home_model.py`, `check_pages.py` (перевірка довжини сторінок ≤ 450 знаків).
Скрипти **не в git** (поза scope C6); якщо оркестратор захоче, їх варто скопіювати в репозиторій (напр. `docs/chapters/_models/`)
як «оракул» для юніт-тестів будівників. Таблиці в документах самодостатні — скрипти не обов'язкові.

Свідомі спрощення (позначені в документах і мають бути підписані в UI як «спрощена/ілюстративна модель»):
- PV: одно-діодна модель без шунта, n = 1, R_s підібрано під P_mp; затінення половинок — через min(G) у ланцюжку.
- Орієнтація: не фізична модель, а таблиця PVGIS (білінійна інтерполяція) — фізична ізотропна модель давала до +19 % похибки для північних схилів.
- Інвертор: ідеальні ключі, лінійний LC, усереднена модель мертвого часу; anti-islanding — лабораторні уставки.
- Батарея: OCV без гістерезису, R₀ + 1RC, температурні множники; старіння й тепловий розгін — **іграшкові** моделі.
- Дім: детермінований PV ясного неба × множник погоди, прилади за розкладом, сталі ККД.

## 6. Відкриті питання

1. Чи робити `labHouse` спільним з розділом `home` (див. §3)?
2. Net billing для домогосподарств в Україні — стан на момент релізу (див. §7); текст написано якісно, без ставок.
3. Чи потрібен у UI симулятора «гривневий» розрахунок окупності? Я свідомо дав лише вартість імпорту за добу — окупність
   залежить від цін обладнання (дуже мінливих) і застаріє найшвидше.
4. Двоколонковий графік «stacked area» і FFT-спектр у `lab-inverter`/`lab-hybrid-home` потребують відповідних компонентів UI-кіту
   (графіки зі стеком, логарифмічні осі) — див. `docs/requests/C6-labs.md`.

## 7. Факти, що застаріють (перевірити перед релізом)

- Рекорди ККД комірок (27,81 % Si HIBC 2025; можливо, вже 28,13 % — пресреліз LONGi 2026, не звірено з NREL), тандем 34,85 %.
- Частки технологій (TOPCon), товщина пластин, витрата срібла — щорічно ITRPV.
- Ціни батарей BNEF (грудень 2025: 108 / 70 $/kWh) — нове опитування щогрудня.
- Тарифи для населення (4,32 грн/kWh, ніч −50 %) і правила «зеленого тарифу»/net billing (закони 3220-IX, 4213-IX, 4777-IX, 4825-IX, проєкти НКРЕКП 2026).
- Параметри «типових» інверторів і час перемикання гібридів (нові моделі щороку).
- Регламент ЄС 2023/1542 — цілі переробки (перегляд можливий у 2028 р.).
- Стандарти: EN 50549-1:2019 (+A1), IEEE 1547-2018 — нові редакції можливі.
