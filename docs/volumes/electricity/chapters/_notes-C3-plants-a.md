## 2. Термінологічні рішення
- **Capacity factor** → «КВВП (коефіцієнт використання встановленої потужності), CF». Усталений український термін енергетиків — КВВП; у тексті скорочуємо до CF після першої появи.
- **Efficiency** → «ККД, η». **LCOE** → «нормована (усереднена) вартість електроенергії».
- **Superheater / reheater** → «пароперегрівник / проміжний пароперегрівник» (нормативна форма на -ник за ДСТУ; не «перегрівач»).
- **Economizer** → «водяний економайзер»; **air preheater** → «повітропідігрівник» (регенеративний — RAH, Ljungström).
- **Water walls** → «топкові (екранні) труби», «екрани топки».
- **ESP** → «електрофільтр»; **FGD** → «сіркоочищення (десульфуризація) димових газів»; **SCR** → «селективне каталітичне відновлення NOx (deNOx)».
- **CHP** → «ТЕЦ, когенерація».
- **HRSG** → «котел-утилізатор»; **CCGT** → «ПГУ (парогазова установка)»; **OCGT** → «ГТУ простого циклу»; **TIT** → «температура газу перед турбіною».
- **Fuel rod** → «твел (тепловидільний елемент)»; **fuel assembly** → «ТВЗ (тепловидільна збірка)»; **RCP** → «ГЦН (головний циркуляційний насос)»; **pressurizer** → «компенсатор тиску»; **containment** → «захисна оболонка (контейнмент)»; **SCRAM** → «аварійний захист (АЗ)»; **ECCS** → «САОЗ (система аварійного охолодження активної зони)»; **decay heat** → «залишкове тепловиділення»; **spent fuel** → «відпрацьоване ядерне паливо (ВЯП)».
- **Penstock** → «напірний (турбінний) водовід»; **wicket gates** → «напрямний апарат»; **runner** → «робоче колесо»; **draft tube** → «відсмоктувальна труба»; **spillway** → «водоскид»; **head** → «напір»; **headwater / tailwater** → «верхній / нижній б'єф»; **pumped storage** → «ГАЕС (гідроакумулювальна електростанція)».
- Швидкість обертання — `rpm` (як у CURRICULUM), а не «об/хв».
- Колір ядерної енергії в Sankey — `teal` (у семантичному коді STYLE_GUIDE для «ядерної енергії» кольору немає; `teal` не зайнятий іншим значенням). Механічна енергія — `mist`.

## 3. Міжрозділові залежності
- **Хаб → C4 (`plant-wind`, `plant-solar`, `plant-geo-bio`, `plant-ocean`, `plant-future`):** хаб містить таблицю порівняння (CF, η, CO₂, LCOE, ramp) і Sankey-частки для вітру, PV, геотермії, біомаси, паливної комірки. Значення взято з IPCC AR5 (2014), Lazard LCOE+ 2026, IRENA 2024. Якщо C4 у своїх розділах дасть інші числа — будівник хабу має взяти значення C4 (або оркестратор має узгодити). Потрібно перевірити: CF вітру (25–40 / 35–55), PV (10–25), CSP (25–50), геотермії (75–90), біомаси (50–80); Sankey: вітер 42 % (при номіналі), PV 19 %, геотермія 12 %, біомаса 30 %, PEM 50 %.
- **Узгоджено з C4 (2026-11-13, за їхніми чернетками):** CF у таблиці хабу — вітер суша 25–45 %, море 40–50 %, PV 10–25 % (нові у світі 2024 р. — 17,4 %, IRENA), CSP зі сховищем 40–70 %, геотермія 75–90 %. Термін «мультиплікатор» (gearbox) і «капсульна турбіна» (bulb) — однакові в обох агентів.
- **Id кроків хабу для посилань з розділів C4 і C3:** межа Карно → `plants/heat-engine`; Rankine → `plants/rankine`; Brayton → `plants/brayton`; паровий острів і градирні → `plants/steam-island`; CF, LCOE, CO₂ → `plants/metrics`; маневреність/black start → `plants/flexibility`; структура генерації → `plants/mix`; галерея → `plants/gallery`. (C4 у своїх нотатках просить ці id — будівникам C4-розділів слід використати їх.)
- **Хаб пояснює** межу Карно, цикли Rankine/Brayton, паровий острів і градирні, CF/LCOE/CO₂/ramp. Розділи станцій (включно з C4: CSP, геотермія, біомаса) мають посилатися на хаб, а не пояснювати це заново.
- **`generator-ac` (C2):** синхронний генератор, n = 60·f/p, синхронізація — посилаємося. **`transformer` (C2):** GSU — посилаємося. **`transmission` (C2):** вихід зі станції, ВРП — посилаємося. **`grid` (C5):** merit order, добовий графік, частота, black start у системі — хаб лише анонсує.
- **`plant-future` (C4):** BESS і паливні комірки — у хабі лише згадано як винятки без турбіни.

## 4. Відкриті питання
- Офіційна структура генерації України за 2024–2025 рр. не опублікована повністю; у хабі — оцінка з позначкою. Оркестратору: якщо до релізу з'являться дані НКРЕКП/Укренерго — оновити.
- Значення «світ 2015» для перемикача у кроці `mix` — орієнтовні (±1 пп).

## 5. Факти, що швидко застаріють
- Світова структура (щороку, Ember — квітень); LCOE (Lazard — щороку червень/липень); рекорди ККД (вугілля, ПГУ); стан ЗАЕС (змінюється щотижня); статус ТЕС/ГЕС України під обстрілами; кількість реакторів у світі та SMR-проєкти; кількість агрегатів Дністровської ГАЕС.
