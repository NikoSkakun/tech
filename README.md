# tech — інтерактивна 3D-енциклопедія про те, як влаштована техніка

Безкоштовний науково-пізнавальний веб-застосунок українською мовою. Кожна тема подається як подорож
**від найнижчого рівня до найвищого**: від явища чи найменшої деталі — до системи планетарного масштабу.
Усе показано в 3D, майже кожен крок можна покрутити, пересунути, зібрати чи запустити власноруч, а за
взаємодіями стоять перевірені фізичні моделі.

**Подивитися:** https://nikoskakun.github.io/tech/

> Проєкт у активній розробці. Зараз доступні перші розділи тому «Електроенергія»; решта з'являтиметься поступово.

## Як це зроблено

- **Vite + TypeScript + three.js (WebGL2)**, власний рушій: рендер-конвеєр із постобробкою, стилізовані матеріали,
  режисер камери, система томів, розділів і кроків із лінивим завантаженням, плавні переходи між масштабами.
- **Інтерфейс у 3D**: панелі, слайдери, графіки, прилади й «Мапа подорожі» — частина WebGL-сцени, без DOM-інтерфейсу.
- **Процедурна графіка і звук**: геометрія, ефекти й звук генеруються кодом — жодних зовнішніх моделей, текстур чи аудіофайлів.
- **Симуляції**: чистий TypeScript без залежності від графіки, покритий модульними тестами.
- **Тексти**: сценарії розділів у `docs/volumes/<том>/chapters/`, з яких генеруються глосарій, індекс і вміст застосунку.
- Жодних зовнішніх залежностей під час роботи: усе роздається як статичні файли; прогрес зберігається в браузері.

## Запуск локально

Потрібні Node.js 24+ і pnpm.

```bash
cd app
pnpm install
pnpm dev          # сервер розробки
pnpm build        # продакшн-збірка в app/dist (працює з будь-якої підтеки)
pnpm typecheck && pnpm lint && pnpm test
```

Перевірка сценаріїв і згенерованих файлів: `python3 tools/content/doccheck.py --all`.
